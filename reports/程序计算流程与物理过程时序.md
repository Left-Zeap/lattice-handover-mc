# 程序物理时序与各阶段物理作用

> 本文对应当前 `continuous_loading` 与桌面 UI 的实际实现，说明一次原子包从
> MOT 计数基准到科学区的先后顺序、每一阶段的物理作用、程序模块、阶段接口
> 和温度口径。文中的默认数值来自项目配置；实验未给出的量仍是工程假设，
> 不能当作实测值。

## 1. 计算边界与完整时间顺序

程序明确区分“实验完整时序”和“数值动力学边界”。MOT 原子数是全链路
留存率的计数分母，但显式动力学从 LGM 开始时刻开始（loading 段 t=0）。

```text
实验前段（程序不重复传播，L1 已开启且静止满功率）
MOT 装载 → CMOT 压缩/等待
                                      │
                                      ▼ LGM 起点初始云（t=0）
程序显式传播
LGM + 静止 L1 装载 → L1 平滑加速 → L1 匀速 → L1 平滑减速
     │                                                    │
     └──── 静止 L1 晶格装载 ──────────────────────────────┘
                                                          ▼
                              L1→L2 handover → L2 加速/匀速/减速
                                                          ▼
                                                   科学区末态汇总
```

LGM 的 11 ms 内 L1 静止且保持恒定满功率；LGM 光关闭后立即开始 L1
运输，不存在 0→满功率 ramp 或额外 hold。loading/LGM 段已进入全链路
四段时间轴（t=0 为 LGM 起点），`phase_space_continuity=True` 时粒子
集合在四段边界直通（见 §9.2）。

### 1.1 默认时长

| 阶段 | 项目默认或参考时长 | 是否由程序显式传播 |
|---|---:|---|
| MOT 装载 | 约 80 ms | 否，只提供计数基准 |
| CMOT + 等待 | 约 8 ms | 否，损失可折叠进 `pre_ramp_survival_fraction` |
| LGM + 静止 L1 装载 | 11 ms（LGM 期间 L1 静止满功率，无 ramp、无额外 hold） | `loading_method=monte_carlo` 时是；否则 LGM 末态云直接作为 L1 初态输入 |
| L1 运输 39 cm | 梯形约 50.00 ms；最小冲击约 51.78 ms | 是 |
| L1→L2 handover | 1 ms | 是 |
| L2 运输 17 cm | 梯形约 21.01 ms；最小冲击约 22.99 ms | 是 |
| 科学区 | 末态汇总 | 不继续传播稳态演化 |

库级默认保留梯形速度轨迹以兼容旧接口；UI 勾选“阶段间连续传递相空间”时，
L1/L2 自动采用最小冲击轨迹。单次程序计算是一条顺序链路；实验装置若以
多原子包流水线实现连续运行，不等于程序把多个原子包同时推进。

## 2. 全链路共同的物理量

### 2.1 光晶格势与移动速度

标准单轴驻波晶格可概写为

\[
V(\rho,q,t)=-U(t)e^{-2\rho^2/w^2}\cos^2[k(q-q_L(t))+\phi],
\]

其中 $U$ 是阱深、$w$ 是束腰、$k=2\pi/\lambda$、$q_L(t)$ 是晶格
位置。真实程序保留前向束、回程束及其干涉项，因此回程功率比小于 1 时
节点不严格为零。移动晶格由两束光频差产生：

\[
\Delta\nu(t)=\frac{2v_L(t)}{\lambda}.
\]

### 2.2 加速势阱与有效势垒

在晶格共动系中，加速度产生惯性倾斜项 $ma q$。程序用临界轴向加速度
$a_c$ 和势垒缩放函数计算有效势垒：

\[
U_{\rm eff}=U\,F_{\rm barrier}(a/a_c).
\]

因此提高加速度会降低束缚势垒；“阱深足够”不自动意味着运输或交接一定
成功。

### 2.3 全链路重力、平衡下垂与径向势垒

全链路采用同一实验室坐标：两条晶格轴位于 $x$-$z$ 平面，$y$ 为公共
竖直轴，重力沿 $-\hat y$。L1→L2 的局部坐标转换绕 $y$ 轴旋转，因此
相空间进入 L2 后重力方向不变，不需要在交接边界重新投影。启用
`include_gravity` 时，loading、L1、handover、L2 的轨迹方程都包含

\[
\mathbf F_g=(0,-mg,0),\qquad V_g=mgy.
\]

对于径向高斯势 $V(y)=-U\exp(-2y^2/w^2)+mgy$，程序求解
$4Uxe^{-2x^2/w^2}/w^2=mg$ 的两个根：较小根给出下垂后的局域极小值，
较大根给出下方鞍点。二者势能差是重力下坡势垒；若高斯光的最大恢复力
$2Ue^{-1/2}/w$ 不足以支撑 $mg$，该势垒置零。最终有效势垒取轴向加速
倾斜势垒与径向重力势垒中的较小者。非连续的热初态从下垂平衡点采样；
连续相空间模式直接沿用上阶段位置，避免每个阶段重复施加一次人工平移。

解析运输只在记录点做上述标量势垒计算；Monte Carlo 的 CPU/GPU 积分则
在原融合力核内增加一个常量 $-mg$，没有增加逐粒子 Python 循环。

### 2.4 温度定义

轨迹级动态温度统一使用去除质心速度后的三维动能方差：

\[
T_{\rm kin}=\frac{m}{3k_B}\left\langle
|\mathbf v-\langle\mathbf v\rangle|^2\right\rangle.
\]

捕获末态还可报告总激发能等效温度。强非平衡阶段，瞬时动能方差只是
“等效动能温度”，不一定代表已经热化的热力学温度。

### 2.5 散射、损失与统计选择

- 晶格光散射按局域非相干光强计算 Poisson 事件；每次事件包含吸收动量
  和各向同性自发辐射反冲。
- 可选背景一体损失和每次散射内态损失以随机 kill 实现；默认系数为零
  时，程序不声称预测真实真空或碰撞损失。
- Monte Carlo 留存率带 Jeffreys 后验标准误，避免在全捕获或零捕获时
  错报零不确定度。
- “升温”应比较同一批最终捕获原子的前后状态；把被选择性丢失的热原子
  排除后得到的降温不能直接解释为冷却作用。

## 3. 阶段 0：MOT、CMOT 与 LGM（输入边界）

这一段在实验中包含辐射压力俘获、磁场梯度、偏振梯度冷却、灰摩尔暗态
冷却等过程，但当前程序不求解光学 Bloch 方程或磁光俘获动力学。

程序只接收以下边界量：MOT 计数原子数、MOT→LGM 起点存活率、LGM 起点
三轴温度、三轴云尺寸、云中心和平均速度。`pre_ramp_survival_fraction`
只负责尚未传播的前级损失，不能再重复乘进 loading 捕获率。

## 4. 阶段 1：LGM + 静止 L1 装载

对应模块：`loading_ramp.py`、`loading_ramp_mc.py`、
`loading_ramp_profiles.py`、`loading_ramp_batch.py`（模块名保留
loading_ramp 仅为兼容既有导入；物理上不存在 0→满功率 ramp 或额外
hold，现行模型见 `LGM静止L1装载模型实现说明.md`）。

### 4.1 初态采样

LGM 起点原子云（Rb 默认 100 µK、三轴云宽 0.5 mm，均为显式工程初值，
需实验标定）按三维高斯位置和各向异性 Maxwell 速度采样；接入全链路时
起点原子数取 `mot_atom_number × pre_ramp_survival_fraction`。晶格
初始相位可固定或逐轨迹随机。L1 在 MOT/CMOT/LGM 前已开启，整个 LGM
窗口内静止且保持恒定满功率。

### 4.2 LGM 窗口：静止晶格中的冷却捕获

L1 功率比例全程为 1，阱深恒定。静止远失谐 L1 本身是近似保守势，
真正提供耗散的是同时作用的 LGM 光场；程序用经验 Langevin 阻尼与扩散
表示（Rb 默认 T_eq 20 µK、τ 1.5 ms，工程参数，应由 LGM 实验标定）。
LGM 窗口内的主要作用是：

1. 经验 Langevin 冷却：速度执行精确 Ornstein-Uhlenbeck 更新；可选
   晶格内 AC Stark 失谐修正（默认关闭）；
2. 晶格光散射产生反冲加热及可选内态损失；
3. 可选光辅助二体损失（需 `density_model='grid'`；三体 K3 为
   not_evaluated）；
4. 全局重力沿 $-y$ 进入动力学；捕获判据同时使用 $mgy$ 总势能和高斯
   阱下方鞍点势垒（`gaussian_gravity_trap`），浅阱无法支撑原子时
   判为不捕获。

数值上采用保守 velocity-Verlet 与耗散/扩散更新组合的 BAOAB 型分裂。
LGM 期间不按能量剔除轨迹，允许冷却再捕获；冷却在 LGM 结束时刻 step
关断，随后立即开始 L1 运输。

### 4.3 LGM 末端：一次捕获判定

LGM 结束时对仍存活粒子统一做一次捕获判定。末态激发能概写为

\[
\epsilon=\frac12m|\mathbf v|^2+U_f e^{-2\rho^2/w^2}
\sin^2(kq+\phi),
\]

只有末态低于含重力修正的局域鞍点势垒、未越过空间边界的原子才进入
捕获集合。输出包括捕获率（Jeffreys 标准误）、捕获原子数、三轴动能
温度、总能量温度、站点占据和捕获相空间集合。L1 入口温度默认取捕获
样本三轴动能温度的几何平均（`kinetic_geometric_mean`，对应实验常用
的释放/飞行时间口径）；总激发能温度保留为非热性诊断量。

### 4.4 三种 loading 使用方式

| 方式 | 行为 | 是否能向后传相空间 |
|---|---|---|
| `legacy_fixed` | 跳过本模块，直接使用配置的 L1 初始原子数和温度 | 否 |
| `moment` | 二阶矩快速诊断，不给出捕获粒子集合 | 否 |
| `monte_carlo` | 正式三维轨迹、散射、冷却和 LGM 末端捕获判定 | 是 |


## 5. 阶段 2：L1 光晶格运输

对应模块：`l1_transport.py`、`transport_mc.py`、`transport_batch.py`、
`control_waveforms.py`。

L1 将原子从 loading 区运输约 39 cm 到 handover 区。束腰默认从
330 µm 变化到 250 µm；理想光学跟随按束腰平方调整功率以近似保持阱深，
也可以用实测位置、速度、加速度、AOM 频差和功率缩放波形替代。

### 5.1 速度与加速度时序

程序保留两种理想轨迹：

**梯形速度 `trapezoid`**：加速度从 0 瞬时跳到 $+a_{\max}$，随后匀速，
再以 $-a_{\max}$ 减速。它兼容旧结果，但阶段边界存在加速度阶跃，解析
模型会计入对应的阶跃加热。

**最小冲击 `minimum_jerk`**：在加速段令

\[
v(t)=v_{\max}S(u),\qquad
S(u)=10u^3-15u^4+6u^5,\qquad u=t/T_a,
\]

\[
T_a=1.875\frac{v_{\max}}{a_{\max}}.
\]

该轨迹在起点和匀速连接点满足速度、加速度和 jerk 连续，减速段镜像对称；
特别适合接在 LGM 结束、静止 L1 装载完成之后。其加速距离较长，因此程序会额外检查
运输距离是否足够。

### 5.2 共动系中的物理作用

在移动晶格共动系中，程序处理：

- 双束完整周期势及其径向/轴向保守力；
- 沿公共竖直轴的重力、平衡下垂和径向下坡逃逸；
- 加速度造成的势阱倾斜和有效势垒下降；
- 束腰与功率沿位置或实测时间波形的变化；
- 局域散射反冲和可选内态损失；
- 可选背景、二体、三体损失与强度/位置噪声接口；
- 超过有效势垒或逃逸边界的粒子损失。

### 5.3 解析预算与轨迹 Monte Carlo

`transport_method="analytic"` 不保存每个原子，按时间积累绝热压缩、散射
反冲、噪声、加速度阶跃和热溢出。最小冲击轨迹没有人为的加速度阶跃项。

`transport_method="monte_carlo"` 用 velocity-Verlet 传播完整经验相空间，
动态温度由相对晶格速度计算。GPU 模式把所有网格点摊平成固定形状粒子
数组，用设备端时间循环并行推进；最小冲击只改变共享运动学预计算，不增加
逐粒子 Python 循环。

L1 末端再次回到零速度、零加速度，随后进入 handover。

## 6. 阶段 3：L1→L2 handover

对应模块：`l1_handover.py`、`handover.py`、`handover_batch.py`。

### 6.1 双晶格交叉势

handover 区同时存在沿 $\hat{e}_1$ 和 $\hat{e}_2$ 的两套晶格，两轴默认夹角
4°。总势为两个时变晶格势之和：

\[
V(\mathbf r,t)=V_1[\mathbf r;f_1(t),\hat e_1]
                 +V_2[\mathbf r;f_2(t),\hat e_2].
\]

无实测波形时，L1 深度比例从 1 线性降到 0，L2 从 0 线性升到 1；也可
读取 `HandoverControlWaveform`。相对相位可固定或逐轨迹随机，用于表示
未锁相或扩展云跨越多个相对相位区域的工程近似。束腰、横向偏移和晶格
残余速度都会进入三维势。

### 6.2 轨迹传播和数值稳定性

每条轨迹在总势中用 velocity-Verlet 传播，并叠加两套晶格的局域散射
反冲。程序按最快轴向阱频自动限制步长满足

\[
\omega_{z,\max}\Delta t\le 1,
\]

再调整为整数步以精确落在 handover 终点。这个限制用于阻止过大步长造成
辛积分器数值能量漂移；CPU 单点和 GPU 批量共用同一公式。GPU 显存分块
仍使用整个逻辑批次统一确定的步长，改变分块大小不会改变结果。

### 6.3 交接捕获判据

handover 结束时 L1 已关闭。程序在 L2 共动系中计算

\[
E_{2,f}=\frac12m|\mathbf v-v_2\hat e_2|^2+V_2(\mathbf r,t_f)+U_2.
\]

只有末态总激发能低于 $U_{2,\mathrm{eff}}$ 的原子才算被 L2 捕获。
无重力时沿用上式；有重力时能量中加入 $mgy$ 并以重力下垂后的势阱最低点
为零点。$U_{2,\mathrm{eff}}$ 取“后续 L2 加速度降低后的轴向势垒”和
“L2 高斯包络的径向重力下坡势垒”两者较小值。
`post_handover_acceleration_m_s2` 只参与终点轴向捕获势垒，不会在
handover 传播期间提前重复施加 L2 加速；重力则在整个 handover 时段持续
存在。

交接率为捕获轨迹数除以输入轨迹数；净 handover 升温比较最终捕获的同一
子样本在初、末两端的总激发能温度。联合动态图在 handover 内显示当前
输入集合的三维动能温度，终点切换为实际进入 L2 的捕获集合，避免从第一帧
就回溯筛选最终捕获者而制造边界跳变。

## 7. 阶段 4：L2 光晶格运输

对应模块：`l2_transport.py`，底层继续复用 `l1_transport.py` 或
`transport_mc.py`。

L2 从 handover 区把捕获原子运输约 17 cm 到科学区，默认束腰从
250 µm 变化到 150 µm。它与 L1 使用相同的偶极势、移动晶格、散射、
势垒、损失和温度计算，但具有独立的距离、峰值加速度、最大速度、时间点、
末端束腰、实测波形和 `kinematic_profile`。

在连续相空间模式下，handover 捕获粒子先旋转到 L2 局部坐标系，再直接
进入 L2 轨迹积分；标量初温采用该集合的三维动能温度，不插入瞬时热化。
在默认约化模式下，只传捕获原子数和总激发能等效温度，等价于假设进入
L2 前或 L2 过程中足够快地再热化。两种口径不能混用解释。

## 8. 阶段 5：科学区末态汇总

程序不继续模拟科学区中的蒸发冷却、碰撞热化、量子简并或多原子包稳态
积累，只根据 L2 末态生成 `ScienceRegionSummary`：

- 科学区原子数和温度；
- 末端晶格阱深、径向/轴向谐振频率；
- 占据格点数和平均每格点原子数；
- 谐振近似下的峰值密度

\[
n_0=\frac{N}{N_{\rm site}}\omega_r^2\omega_z
\left(\frac{m}{2\pi k_BT}\right)^{3/2}.
\]

全链路相对 MOT 的留存为各阶段留存的乘积：

\[
S_{\rm total}=S_{\rm pre}\,\eta_{\rm load}\,
S_{L1}\,\eta_{\rm HO}\,S_{L2}.
\]

`pre_ramp_survival_fraction` 与 loading 捕获率各出现一次，不能重复计数。

## 9. 阶段接口：约化传递与连续相空间

### 9.1 默认约化接口

阶段之间只传原子数 $N$ 和温度 $T$。下一个阶段重新采样热分布，内存
小、适合二维扫描和 GPU 固定形状批量，但会丢失位置—速度相关、格点占据、
非高斯尾部和相干集体运动。

### 9.2 连续相空间接口

`FullChainInputs.phase_space_continuity=True` 时，单点和二维扫描都走连续相空间模式：

```text
loading 捕获集合（LGM 末端判定）
  → L1 局部相空间
  → 平移到 handover 局部原点
  → handover 捕获集合
  → 旋转到 L2 局部坐标
  → L2 末态
```

固定粒子数接口需要调整样本数时使用低方差系统重采样；输入和目标粒子数
相同且权重相等时直接复制，不再随机 bootstrap。联合轨迹在
loading→L1、L1→handover 和 handover→L2 的重复时间戳处使用一致温度
口径，有限样本重采样波动不画成物理脉冲。

连续模式要求 loading 与运输腿都采用 Monte Carlo，且禁止梯形加速度
阶跃：无实测波形时 L1/L2 强制 minimum_jerk，梯形直接在库层报错；
`TransportControlWaveform`/`HandoverControlWaveform` 可导入实测波形。
二维扫描在 CPU 上逐点运行，在 GPU 上按 loading/L1/handover/L2 四段
固定形状批量推进，粒子集合只在阶段边界按网格索引传递。

## 10. 程序数据流与时间轴

```text
FullChainInputs
  ├─ L1HandoverInputs
  │    ├─ L1TransportInputs
  │    └─ handover 数值/几何参数
  └─ L2TransportInputs

LoadingRampResult
  └─ N,T 或 CapturedEnsemble
       ↓
L1TransportTrace / L1DesignPoint
  └─ L1 末温、末态原子数、阱深、散射率、末态相空间
       ↓
HandoverParameters → HandoverResult
  └─ 交接率、捕获温度、Captured ParticleEnsemble
       ↓
L2TransportResult
  └─ leg_trace + ScienceRegionSummary
       ↓
FullChainPointSimulation / FullChainCombinedTrace
```

`FullChainCombinedTrace.phase` 使用四个阶段名：`LGM + static L1
loading`、`L1 transport`、`handover`、`L2 transport`，t=0 为 LGM
起点。阶段交界允许重复时间戳，
表示前一阶段末点和后一阶段首点是同一物理时刻，不表示多演化了一步。

## 11. 每阶段物理作用矩阵

| 阶段 | 保守力/势 | 耗散或冷却 | 随机作用 | 损失/选择 | 主要观测量 |
|---|---|---|---|---|---|
| MOT/CMOT/LGM | 磁光势、偏振梯度等未建模 | 实验冷却未显式求解 | 未建模 | 前级存活率 | 输入 $N,T,\sigma$ |
| LGM + 静止 L1 装载 | 静止满功率 L1 周期势；全局重力 | 经验 Langevin 阻尼（LGM 末端 step 关断） | 冷却扩散、散射反冲、随机相位 | 空间边界、重力修正鞍点势垒、背景/内态/可选二体损失、LGM 末端一次捕获判定 | 捕获率、捕获温度、格点占据 |
| L1 运输 | 移动双束周期势、惯性倾斜、重力、束腰/功率变化 | 无显式激光冷却 | 散射反冲、可选噪声 | 轴向加速势垒与径向重力势垒、可选损失 | 末温、留存、AOM 频差、有效势垒 |
| handover | 两套交叉时变晶格势与持续重力 | 无显式冷却 | 两晶格散射、随机相对相位 | L2 轴向倾斜/径向重力最小势垒捕获 | 交接率、捕获温度、MC 标准误 |
| L2 运输 | L2 移动周期势、惯性倾斜、重力、束腰收缩 | 无显式冷却 | 散射反冲、可选噪声 | 轴向加速势垒与径向重力势垒、可选损失 | 科学区末温与留存 |
| 科学区汇总 | 末端谐振近似 | 未继续演化 | 未建模 | 未继续演化 | 密度、频率、每格点原子数 |

## 12. 最重要的时序和物理配置

| 配置/界面字段 | 物理意义 | 主要影响 |
|---|---|---|
| `pre_ramp_survival_fraction` | MOT 计数到 LGM 起点的前级存活 | 全链路绝对原子数 |
| `include_gravity` / UI“全时序重力” | 是否统一施加 $\mathbf F_g=(0,-mg,0)$ | 下垂位置、径向势垒、捕获与留存；默认开启 |
| `loading_lgm_duration_ms` | LGM 装载时长（静止满功率 L1，无 ramp） | 冷却接近平衡的程度与捕获 |
| `loading_cooling_*` | 经验冷却阻尼、目标温度（end=LGM 时长，step 关断） | loading 冷却与扩散 |
| `l1/l2_kinematic_profile` | 梯形或最小冲击速度轨迹 | 加速度阶跃、运输时长和距离要求 |
| `acceleration_m_s2`、`maximum_velocity_m_s` | 移动晶格运动学上限 | 倾斜势垒、运输时长、AOM 啁啾 |
| `detuning_ghz`、`source_power_w` | 偶极势深与散射率 | 束缚裕量和反冲加热 |
| `retro_power_ratio`、`waist_um` | 驻波调制度和空间包络 | 轴向/径向频率、临界加速度 |
| `duration_us`、`crossing_angle_deg` | handover 快慢与几何失配 | 交接率和非平衡激发 |
| `time_step_us` | handover 数值步长请求值 | 自动受轴向阱频稳定条件限制 |
| `transport_time_step_us` | L1/L2 MC 步长 | 运输轨迹精度与耗时 |
| `phase_space_continuity` | 是否传完整经验相空间 | 物理保真度；单点/扫描均支持，禁止梯形阶跃 |
| 三个 control waveform 路径 | 实测 L1/handover/L2 控制 | 接管相应理想时序字段 |

主要配置文件：

- `data/loading_ramp_defaults.json`：LGM 起点云、静止晶格、冷却、loading 损失和数值参数；
- `data/l1_transport_defaults.json`：L1/L2、handover、扫描、光路、损失和噪声；
- 实测波形 CSV：优先于相应理想运动学或深度 ramp。

## 13. 结果解释时必须保留的模型边界

1. 这是经典质点模型，不含 Bloch 能带、Landau-Zener 隧穿、量子相干输运、
   矢量/张量光移和内部态光学 Bloch 动力学。
2. Langevin loading 冷却是经验模型，阻尼时间和目标温度必须由实验标定；
   默认值不能视作测量结果。
3. handover 内及科学区中的碰撞热化没有显式传播；约化接口的总能量温度
   等价于附加了再热化假设，连续接口则没有。
4. 二体、三体、背景和内态损失默认关闭时，留存率主要反映势垒选择和轨迹
   逃逸，不是完整实验寿命预测。
5. 未提供实测控制波形时，束腰、功率跟随、相对相位、云尺寸和交叉几何中
   的部分数值是工程假设，应和计算结果一起报告。
6. 非平衡 handover 中的瞬时动能尖峰只有在步长收敛、统计总体一致且排除
   重采样噪声后才能解释为真实相空间激发。
7. 重力径向势垒采用局部等效单高斯包络；标准等腰驻波为精确径向模型，
   offset-waist 双束和 handover 两束同时存在时属于局部有效包络近似。轨迹
   力仍使用完整双束/双晶格势，近似只用于标量逃逸势垒。
