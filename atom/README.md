# `atom`：原子知识文档

这个目录保存不同原子体系的教学型知识库。它回答“这种原子有哪些
重要能级、波长和工程风险”，不直接参与 Python 数值计算。

## 文件

| 文件 | 内容 |
|---|---|
| [`Rb87.md`](Rb87.md) | Harvard 连续运行方案的参考原子，包含 D 线、MOT、移动晶格和 shielding 背景 |
| [`Cs133.md`](Cs133.md) | 当前目标原子，包含 D 线、冷却、光镊、Rydberg 和连续装载风险 |
| [`Yb171.md`](Yb171.md) | Princeton 亚稳态连续替换方案的参考原子 |

## 推荐阅读方式

如果目标是把 Rb 方案迁移到 Cs：

1. 先读 `Rb87.md` 的“连续装载论文中的关键光场”；
2. 再读 `Cs133.md` 的 D 线和连续装载风险；
3. 对照两者的“可迁移/不可迁移”内容；
4. 最后读 `Yb171.md`，理解亚稳态隔离为什么是另一条技术路线。

## 与代码的关系

程序实际使用的 Rb-87 和 Cs-133 质量、D1/D2 波长及线宽定义在
[`../continuous_loading/atomic.py`](../continuous_loading/atomic.py)。

两处内容的区别：

- 本目录面向人阅读，包含实验背景、来源和风险；
- `atomic.py` 面向程序，只保留计算需要的常数。

修改关键 D 线数值时，应同时检查文档和代码，并运行：

```powershell
python -m pytest tests\test_atomic_and_lattice.py -q
```

## 数据等级

文档中的参数可能属于三类：

- 精确或权威原子常数；
- 论文实测装置参数；
- 尚待验证的候选设计或数量级估算。

阅读时要看“来源”“等级”“参数性质”等列，不要把候选波长或工程
估算写成已经验证的实验结论。

## 注意

当前 Python 包只实现碱金属 Rb-87 和 Cs-133 的 D1/D2 标量模型。
`Yb171.md` 是方案比较资料，Yb 尚未接入正式计算代码。
